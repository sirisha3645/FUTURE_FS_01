## 🚀 Project Overview

This portfolio is a modern, responsive, and interactive web application designed with a **"Glassmorphism"** aesthetic. It provides a comprehensive view of my professional profile, from my educational background at Mohan Babu University to my technical expertise in programming and UI/UX design.

### ✨ Key Features
- **Modern UI Design:** High-quality purple theme with glassmorphism effects and custom CSS animations.
- **Dynamic Hero Section:** Smooth typing animations and a unique "morphing" profile image container.
- **Interactive Project Showcase:** Detailed cards for projects like *Any Time Rider (ATR)* with direct links to source code.
- **Functional Contact Form:** A fully operational contact section integrated with **Web3Forms API**, allowing visitors to send messages directly to my email without any backend overhead.
- **Fully Responsive:** Optimized for a seamless experience across mobile, tablet, and desktop devices.
- **Scroll Reveal Animations:** Interactive elements that fade and slide into view as the user scrolls.
